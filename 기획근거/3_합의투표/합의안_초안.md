## 1. 프로젝트 근거 결론 [일치]

1. "바이브 코딩 개발자"는 국내에서 정착된 직무명이 아니다. 일부 중소기업 공고에 직함으로 등장하지만 JD가 빈약하다. 주류는 **일반 개발 직무 + AI 도구 활용·검증 역량의 우대 또는 전형 평가**(무신사 2차 AI 도구 활용 테스트, 컬리, 넥슨, LG CNS, CJ 등)다.
2. 신입 시장은 축소됐다(SPRi 신규 채용 비중 62.6% → 24.0%, KLI 등). 백엔드는 지원 비중이 공고 비중보다 크다(공급 과잉). DevOps·운영은 반대다(사람인·점핏 2025 상반기).
3. 그래서 **"AI로 만들었다"가 아니라 "AI로 만든 것을 검증하고 운영할 수 있다"**를 증명해야 한다.
4. **락 비교 실험과 선착순 동시성 측정은 차별화가 아니라 최소 자격(table stakes)이다.** 근거는 항해 플러스 주차 과제, 인프런 3,654명 강좌, GitHub '선착순' 402개, 동일 설계 공개 저장소다. 빼면 감점, 넣어도 가점은 작다.
5. 전형이 갈라져 있다. 네이버·카카오는 코딩테스트에서 AI를 금지하고, 무신사는 1차에서 약 76%가 탈락했으며, 넥슨은 코딩테스트를 폐지하고 AI 평가로 대체했다. **코딩테스트와 면접 방어력은 포트폴리오와 별개의 관문이다.**
6. 위 근거의 상당 부분은 경력직 공고에서 나왔고, **신입 공고 원문 표본이 부족하다**(이번 라운드 보강 조사 대상).

- **권장**: EC2 + RDS db.t4g.micro(+gp3 20GB), Redis는 앱 서버 동거 ≈ $57.6 ≈ 7.8만 원/월. 관리형 Valkey를 더하면 ≈ $71.7 ≈ 9.7만 원/월
- **부하 테스트**: c7g.large $0.0816/h × 대수 × 시간 + DB 상향분(예: 3대 × 8시간 ≈ 4천~7천 원/회). 끝나면 즉시 삭제
- **NCP**: 공식 요금 미확인. 참고값은 2vCPU/8GB 약 8.2만 원 + VAT, 크레딧 10만 원(3개월), Micro 1년 무료. 채용 키워드(AWS 1,404~1,501 vs 네이버클라우드 174~263) 근거로 **AWS 우선**
- **계정**: 신규 크레딧(최대 $200)과 무료 플랜(6개월)은 가입 시점부터 흐르므로, 전환 직전에 가입한다. 무료 플랜이 끝난 뒤 데모를 유지하려면 유료 전환이 필요하다.
- **전환 시점**: R2까지는 로컬(Docker Compose, 웹훅은 터널)로 진행한다. 다음 중 하나라도 해당하면 전환한다: ① 첫 지원 4~8주 전 ② 부하 수치를 포트폴리오에 쓸 때 ③ 배포·장애·복구 기록을 남길 차례일 때. 1일 차부터 12-factor 설정과 컨테이너화를 해 둔다.

## 8. 기획서에 리스크·후속 과제로 명시할 것 [일치 예상, 이견 있으면 표시]
- 같은 모델 편향: 세 에이전트가 같은 검색 결과 집합에서 수렴했다.
- "무신사 근거가 많다 → 패션"의 순환 가능성: 기사 노출 편향
- 신입 공고 표본 부족(보강 조사로 일부 해소 예정)
- 프론트엔드 신입 공고 근거 부족
- 실사용 증거(지인 베타 등)는 미조사
- 이벤트 로깅·전환 퍼널·A/B 실험 미포함(C 지적 → 포함 여부 투표)

- "바이브 코딩 직함" 중소기업 세그먼트는 빠른 MVP 출시 능력을 원할 수 있음
- 포트원 V2 테스트 채널에서 가상계좌가 되는지 미확인
- 상품 데이터 수천 SKU 생성 방법(저작권 없는 생성)
