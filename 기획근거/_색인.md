# 기획근거 색인

이 폴더는 기획서 v0.2와 작업진행 문서가 나오기까지의 근거와 이력을 보관한다. **읽기 전용이다. 결정은 `../기획서.md`와 `../작업진행.md`에만 있고, 여기 내용과 다르면 그 두 문서가 기준이다.** 언제 이 폴더를 여는지는 `../CLAUDE.md` §4에 있다.

## 1. 단계 관계

번호는 작업 순서다. 앞 단계의 산출물이 다음 단계의 입력이 된다.

```
0_의뢰원문 → 1_독립조사(A·B·C 각자) → 2_교차검증(서로의 제안 평가)
→ 3_합의투표(합의안 초안 + 섹션별 투표 + 공고 보강 조사) → 4_기획서_구판(v0.1)
→ 5_외부비평(비평 3회 + 결정 문답) → ../기획서.md(v0.2, 현재 기준)
→ 6_검토승인요청(v0.2를 개발자 검토용으로 다시 묶은 보고서)
→ ../작업진행.md(작업 규칙·계약·작업 목록) ← 7_작업진행근거(그 결정 과정)
```

## 2. 질문별로 찾는 순서

각 순서에서 앞의 문서로 답이 나오면 거기서 멈춘다.

| 찾는 것 | 순서 |
|---|---|
| 이 결정을 왜 했나(v0.2 변경분) | 기획서 §19-6 → `5_외부비평/v0.2_결정문답.md` → 해당 `비평_n차.md` |
| 비평에 어떻게 반박·수용했나 | 기획서 §19-7 → `5_외부비평/비평_n차.md`의 "코디네이터 답변" |
| 합의 과정, 조건부 동의, 코디네이터 판단 | 기획서 §19-1·19-4 → `3_합의투표/합의안_초안.md` → `투표_공고조사_*.md`의 "섹션별 투표" |
| 채용 공고 원문 링크 | 기획서 §1-2 → `3_합의투표/투표_공고조사_*.md`의 보강 조사 부분 |
| 수치·통계의 출처 | 기획서 §1 → `2_교차검증/검증_*.md`의 "직접 재확인한 출처 표" → `1_독립조사/조사_*.md`의 "출처 목록"(Grep으로 해당 줄만) |
| 사용자의 원래 요구 문구 | `0_의뢰원문.md` |
| v0.1과의 차이 | 기획서 맨 앞 "v0.1 → v0.2 변경 요약" → 그래도 필요하면 `4_기획서_구판/기획서_v0.1.md`의 해당 § |
| 작업 방식(테스트·Git·구현 문서·디자인·관리자 보안)을 왜 이렇게 정했나, 면접용 설명 | `../작업진행.md` E3 → `7_작업진행근거.md`의 해당 라운드 → 4절 면접 예상 질문 |
| ADR-004~006 검토 질문 | `6_검토승인요청/기획서_v0.2_검토보고서.html`에서 `Grep "RP-"`로 해당 항목만 |
