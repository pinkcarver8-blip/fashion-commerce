# 미확정·임시방편 목록

작업진행.md A7. 임시로 때운 곳, 확실하지 않은 곳, 버그 후보를 적는다. 해소되면 행을 지우고 PR에 적는다.

| # | 위치 | 무엇 | 이유 | 해소 조건 |
|---|---|---|---|---|
| K1 | `backend/.../architecture/CommerceArchitectureRules.java` 소수 타입 규칙 | 메서드 호출 없이 계산식 안에서만 쓰는 소수(예: `(long) (price * 0.9)`)는 잡지 못한다 | ArchUnit은 클래스 파일의 필드·서명·호출만 보고, 계산 명령까지는 보지 않는다 | 금액 계산 코드 리뷰에서 확인한다. 금액 계산 단위 테스트(R1-06)가 기대값으로 잡는다 |
| K2 | 같은 파일, 모듈 경계·주문 상태·주문상품 규칙 | 리플렉션으로 필드를 바꾸거나 다른 모듈 클래스를 쓰는 것은 잡지 못한다 | 리플렉션은 클래스 파일에 대상이 드러나지 않는다 | 리뷰. 업무 코드에서 리플렉션을 쓰는 PR은 이유를 적는다 |
| K3 | 같은 파일, 관리자 경로 규칙 | `@RequestMapping` 계열 표시(상위 클래스·인터페이스 포함)만 본다. 함수형 라우팅(`RouterFunction`)으로 연 경로는 잡지 못한다 | 함수형 라우팅의 경로는 실행 중에 만들어진다 | 함수형 라우팅을 쓰지 않는다. 쓰게 되면 이 규칙을 넓힌다. 최종 방어는 보안 필터 체인의 `/api/admin/**` 규칙(ADR-008)과 R1-03 엔드포인트 자동 검사 |
| K4 | 같은 파일, 주문·주문상품 규칙 | 지금 실제 코드에 `Order`·`OrderItem`이 없어 규칙이 검사할 대상이 없다. 위반 예시(`archfixture`)로만 동작을 확인했다 | 클래스는 R1-06·R1-08에서 만든다 | R1-06·R1-08 착수 때 이름을 확인한다(작업진행.md E4-2) |
| K5 | 같은 파일, 주문상품 규칙 | Hibernate 바이트코드 강화(enhancement)를 켜면 엔티티 안에 필드 쓰기 메서드가 생겨 규칙이 실패할 수 있다 | 강화 플러그인이 만든 코드도 클래스 파일에 들어간다 | 강화를 켜지 않는다. 켜야 하면 그 PR에서 규칙의 예외를 정한다 |
| K6 | 같은 파일, 주문상품 규칙 | 주문상품 필드 타입으로 record를 허용하는데, 그 record 안에 목록이 있으면 내용을 바꿀 수 있다 | record 구성 요소까지 따라가 검사하지 않는다 | 주문상품에 쓰는 record는 리뷰에서 구성 요소를 확인한다 |
| K7 | 같은 파일, 모듈 경계 규칙 | 컴파일할 때 값이 박히는 상수(`static final` 기본형·문자열)와 메서드 호출 없는 형 변환은 의존으로 보이지 않는다 | 컴파일러가 상수 값을 복사해 넣어 클래스 파일에 원래 클래스가 남지 않는다 | 리뷰. 값이 다른 모듈의 내부 상수에 기대는지 본다 |
| K8 | 같은 파일, 소수 타입 규칙 | `@AllowDecimal` 필드가 있는 클래스에 Lombok `@Builder`를 달면 빌더 코드가 실패한다 | Lombok은 표시를 빌더 필드·메서드까지 복사하지 않는다 | 그런 클래스에는 `@Builder`를 쓰지 않고 생성자를 쓴다 |
| K9 | 같은 파일, 소수 타입 규칙 | 재시도 간격의 무작위 흔들기(`ThreadLocalRandom.nextDouble`), Spring `ExponentialBackOff(long, double)`, 지표 기록(`record(double)`)도 막힌다 | 돈이 아니어도 소수 타입 전부를 막기로 했다(ADR-010 보충) | 쓰는 메서드마다 `@AllowDecimal(reason)`을 단다. 의도한 동작이다 |
| K10 | 같은 파일, 주문상품·주문 상태 규칙 | 주문상품의 `@PrePersist`가 필드를 채우거나, `Order` 안의 중첩 클래스가 상태를 바꾸면 실패한다 | 생성자 밖·`Order` 밖의 쓰기로 본다 | 의도한 동작이다. 생성 시각은 생성자에서 채운다 |
| K11 | 같은 파일, 공유 모듈 허용 목록 | 목록에 있는 함수의 속(계산 내용)을 바꾸는 것은 잡지 못한다. 예: `Money.plus`가 수수료를 더하게 고친다 | 목록은 이름과 매개변수만 본다 | `Money` 단위 시험(R1-06)과 코드 읽기 |
