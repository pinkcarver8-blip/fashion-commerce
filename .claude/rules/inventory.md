# [엄격] 재고·원장·동시성

원문: 작업진행.md A5-2, 계약은 B4, 불변식은 B8(I1~I3). 작업 전에 이 원문과 이슈의 시나리오를 먼저 읽는다.

- 모든 재고 증감은 같은 트랜잭션에서 원장에 한 줄씩 기록한다. 원장은 추가만 한다(수정·삭제 금지).
- 기본 방식은 조건부 원자 UPDATE(`qty >= n`, 영향 행 수 확인)다. 여러 SKU는 ID 순으로 잠근다.
- 재고의 원천은 MySQL이다. Redis에 재고 원천을 두지 않는다.
- 동시성 시나리오는 동시성 테스트로 고정하고, 끝에 불변식(초과판매 0, 원장 합계 = 현재 재고)을 검사한다.
