# [엄격] DB 스키마·마이그레이션

원문: 작업진행.md A5-4.

- Flyway 마이그레이션은 앞으로만 추가한다. 이미 적용한 파일은 고치지 않는다. 되돌릴 때는 되돌리는 새 마이그레이션을 쓴다.
- 컬럼 삭제·이름 변경은 expand/contract 순서로 한다.
- 마이그레이션은 기능 브랜치 안에서 별도 커밋으로 둔다. `git revert`로는 DB가 되돌아가지 않는다.
- 원장 테이블은 추가만 가능하게 설계한다. 멱등키에는 유니크, 수량에는 CHECK 제약을 둔다.
