# [엄격] 상태 머신

원문: 작업진행.md A5-3, 계약은 B3(ADR-004·006a), 불변식 I6.

- 전이 규칙은 코드 한 곳에서만 정의한다. 허용되지 않은 전이는 거부한다.
- 종결 상태(EXPIRED, CANCELLED)는 어떤 경우에도 되살리지 않는다.
- 상태 전이 규칙표는 단위 테스트로 고정한다.
- 주문 상태 전이는 주문 행을 잠근 뒤(`SELECT … FOR UPDATE`) `Order`의 도메인 메서드로만 한다. 이미 목표 상태면 아무것도 바꾸지 않는다. 사용자 요청의 허용되지 않은 전이는 409, 외부 신호(웹훅·폴링·작업자)는 무시하고 경고 로그(ADR-004).
